# Prompt set

The assets were generated individually with the following common production
prompt and the per-file subject directives below.

## Shared production prompt

> Create a centered 512×512 educational web-interface icon as polished
> NES/Game Boy Advance pixel art. Use deliberate blocky pixel clusters, flat
> colors, and hard edges; no gradients, blur, anti-aliasing, painterly texture,
> photorealism, text, labels, borders, shadows, floor, or watermark. Keep at
> least 15% clear padding and nothing touching an edge. Use only #F4EFE6,
> #FF4D7E, #33F1E6, #FFD84D, #1F1A3B, #5B4A96, and #0B0A18. Render on one
> perfectly uniform #00FF00 chroma-key background, never using that color in
> the subject, for conversion to alpha transparency.
